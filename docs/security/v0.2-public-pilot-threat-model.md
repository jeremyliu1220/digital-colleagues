# v0.2 Public Pilot Threat Model

Status: P9 planning contract. This model extends the accepted v0.1 local-reference threat
model for future P10-P15 work. It is not evidence of implementation, security
effectiveness, named-provider compatibility, or production readiness.

## Assets and trust boundaries

Future assets include exact AgentPackage artifacts and attestations; trust/revocation
decisions; ColleagueDeployment namespaces; OpenAI and Microsoft 365 connections; delegated
tokens; ConnectorGrants; SourceReferences/Cursors; temporary external bodies; budgets;
AutomaticEffectAuthorizations; HumanApprovalDecisions; effect attempts/results; and causal
audit.

The Admin UI, package metadata/content, localized prompts, model output, provider responses,
external messages/documents, download redirects, and cached cursors are untrusted data.
Authentication does not grant resource/action authority. The existing server-side Mandate,
Policy, namespace, role, approval, replay, attempt, reconciliation, and audit boundaries
remain authoritative.

## Automatic effect policy

Automatic eligibility requires exact proof for an existing internal email thread or
Admin-allowlisted Teams chat with unchanged original participants, same tenant, no
attachment, no new mention, and routine reply; or a Planner action whose plan, task,
fields, assignee, ETag/data version, Mandate, Policy, ConnectorGrant, and budget all match.

New recipient, new chat, external domain, attachment, new mention, cross-tenant effect, or
ambiguous binding/version/risk requires HumanApprovalDecision. Anything beyond current
authority, stale, revoked/expired, over budget/rate, cross-Agent/cross-tenant, self-granting,
or unprovable is denied.

## Evidence and residual risks

P9 records `static` and `synthetic_offline` controls only. Actual OpenAI project access,
Microsoft 365 tenant/App/account/consent behavior, live effect delivery, human outcomes,
FileVault/encrypted-volume enforcement, and 72-hour ten-Agent behavior are
`not_evaluated`. P15 live work requires private storage and cannot use mock, stub, or
loopback substitutes.

Residual Public Pilot risks include local-operator compromise, browser/session compromise,
provider retention and behavior outside the client contract, delegated-account compromise,
Microsoft 365 service/API changes, prompt injection in external bodies, public supply-chain
compromise, one-host availability loss, and operator failure to secure private state. This
plan claims no production security/privacy, enterprise IAM, HA, compliance, tenancy, or
production readiness.
