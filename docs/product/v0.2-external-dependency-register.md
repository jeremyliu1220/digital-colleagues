## Fixed interpretation

- If `gpt-5.5` becomes unavailable or incompatible, P13 stops for a Change Decision; it
  does not silently choose a different model.
- If delegated device code, Teams dated polling, Planner ETag, selected SharePoint access,
  or GitHub attestation cannot satisfy the fixed contract, the owning phase stops for a
  Change Decision instead of changing provider, OAuth flow, relay/webhook design, or
  permission mode.
- Static documentation is not live compatibility. No mock, stub, or loopback outcome may
  be labeled `live_private` or named-provider acceptance.
- No credential is requested in conversation or stored in this repository.
